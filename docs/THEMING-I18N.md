## ۱. ⚡ سرعت

### مشکل

کل اپ در **یک باندل ۵۷۸ کیلوبایتی** بود. مرورگر باید همه‌چیز — از جمله React Flow که ۲۸۶ کیلوبایت است — را قبل از نمایش اولین پیکسل دانلود و پارس می‌کرد.

### راه‌حل

**تقسیم کد بر اساس مسیر.** فقط Dashboard و Projects از ابتدا لود می‌شوند؛ بقیه با `lazy()` هنگام نیاز می‌آیند.

**جداسازی وندورها** در `vite.config.ts` تا تغییر یک دکمه، کل کش کاربر را باطل نکند.

### نتیجه

| | قبل | بعد |
|---|---|---|
| باندل اولیه | ۵۷۸ KB | **۶۵ KB** |
| فشرده (gzip) | ۱۷۵ KB | **۲۰ KB** |

React Flow (۲۸۶ KB) فقط وقتی دانلود می‌شود که واقعاً طراح دیتابیس را باز کنی.

### گزینهٔ «کاهش انیمیشن»

در تنظیمات یک کلید اضافه شد که همهٔ ترنزیشن‌ها را به صفر می‌رساند — برای سیستم‌های ضعیف. تنظیم `prefers-reduced-motion` سیستم‌عامل هم به‌صورت خودکار رعایت می‌شود.

## ۲. 🎨 پوسته

### چرا کار نمی‌کرد

مقدار `theme` ذخیره می‌شد ولی **هیچ‌جا خوانده نمی‌شد**. رنگ‌ها مستقیم در `tailwind.config.js` هاردکد شده بودند.

### راه‌حل

هر رنگ حالا یک **CSS variable** است. عوض کردن پوسته یعنی نوشتن چند متغیر روی `<html>` — بدون رندر مجدد، بدون پرش.

```
--cf-bg  --cf-sidebar  --cf-card  --cf-txt  --cf-muted
--cf-well  --cf-raise  --cf-line  --cf-primary  --cf-hover
```

### چهار پوستهٔ آماده

| | | |
|---|---|---|
| **Dark** | پیش‌فرض | `#0F172A` |
| **Light** | روشن و کم‌کنتراست | `#F8FAFC` |
| **Midnight** | مشکی خالص، OLED | `#09090B` |
| **Nord** | آبی-خاکستری ملایم | `#2E3440` |

هر کارت در تنظیمات یک **پیش‌نمایش کوچک از خود پوسته** نشان می‌دهد.

**۸ رنگ اصلی** هم قابل انتخاب است؛ رنگ hover خودکار از روی آن محاسبه می‌شود.

آیکون ماه/خورشید در نوار بالا بین پوسته‌ها می‌چرخد.

### بدون پرش هنگام باز شدن

`main.tsx` پوستهٔ ذخیره‌شده را از `localStorage` می‌خواند و **قبل از mount شدن React** اعمال می‌کند.

## ۳. 🌍 زبان و RTL

### هشت زبان

| | | جهت |
|---|---|---|
| English | انگلیسی | LTR |
| **فارسی** | Persian | **RTL** |
| **العربية** | Arabic | **RTL** |
| Español · Deutsch · Français · Türkçe | | LTR |
| 简体中文 | Chinese | LTR |

فونت هر خط نوشتاری جداگانه تنظیم می‌شود (Vazirmatn برای فارسی، Noto برای عربی و چینی).

### راست‌به‌چپ واقعی

با انتخاب فارسی یا عربی:

- ✅ سایدبار به راست منتقل می‌شود
- ✅ چیدمان کامل آینه می‌شود
- ✅ فونت مناسب اعمال می‌شود

به‌جای `ml-auto` و `text-left` از **ویژگی‌های منطقی** (`ms-auto`، `text-start`، `border-s`) استفاده شد که خودشان با جهت صفحه برمی‌گردند.

### چه چیزهایی عمداً LTR می‌مانند

این‌ها **نباید** برگردند، حتی در حالت راست‌به‌چپ:

| بخش | چرا |
|---|---|
| دکمه‌های ✕ ⬜ ➖ | باید از قرارداد سیستم‌عامل پیروی کنند |
| کانواس دیتابیس | نمودار طبق قرارداد از والد به فرزند خوانده می‌شود |
| نام جدول و ستون | شناسه‌های کد هستند |
| SQL، JSON، پیش‌نمایش کد | کد همیشه چپ‌به‌راست است |
| مسیرها و اندپوینت‌ها | `/api/users/{id}` |

این با `dir="ltr"` روی همان المان‌ها و چند قانون CSS انجام شد.

### ترجمهٔ ناقص؟ مشکلی نیست

جستجوی کلید به این ترتیب است: زبان انتخابی → انگلیسی → خود کلید. یعنی یک ترجمهٔ جاافتاده باعث صفحهٔ خالی نمی‌شود.
