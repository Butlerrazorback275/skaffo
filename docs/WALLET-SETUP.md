# 💰 راهنمای گرفتن آدرس کیف پول از Trust Wallet

قبل از هر چیز، **مهم‌ترین قانون**:

> 🔴 **هرگز عبارت ۱۲ کلمه‌ای (Seed Phrase) را به هیچ‌کس نده — از جمله من.**
>
> چیزی که برای دریافت دونیت لازم است فقط **آدرس عمومی** است. آدرس عمومی
> مثل شمارهٔ کارت است؛ با آن فقط می‌شود پول *فرستاد*، نه برداشت.
> اگر جایی از شما seed phrase خواست، کلاهبرداری است.

| شبکه | شروع می‌شود با | طول | نمونه |

## مرحله به مرحله در Trust Wallet

### ۱. USDT روی شبکهٔ TRON — این را اول بگیر

چرا اول؟ چون کارمزد انتقالش تقریباً صفر است و رایج‌ترین گزینه بین کاربران ایرانی است.

1. Trust Wallet را باز کن
2. روی **Receive** (دریافت) بزن
3. در جستجو بنویس `USDT`
4. ⚠️ **دقت کن**: چند تا USDT می‌بینی. حتماً آن که کنارش نوشته **TRON** یا **TRC20** را انتخاب کن
5. آدرسی که با `T` شروع می‌شود را کپی کن

### ۲. Bitcoin

1. **Receive** → جستجو `BTC` → **Bitcoin**
2. آدرسی که با `bc1` شروع می‌شود را کپی کن

### ۳. Ethereum

1. **Receive** → جستجو `ETH` → **Ethereum**
2. آدرسی که با `0x` شروع می‌شود را کپی کن

> 💡 همان آدرس `0x` برای USDT روی شبکهٔ ERC20 هم کار می‌کند — ولی کارمزد
> اتریوم بالاست و برای دونیت‌های کوچک به‌صرفه نیست.

## کجا باید بگذاری‌شان

### فایل اول — داخل برنامه

`src/plugins/support/Support.tsx`

```ts
const WALLETS = [
  { id: 'usdt', label: 'USDT',     network: 'TRC20 (Tron)',     address: 'PASTE_TRC20_ADDRESS' },
  { id: 'btc',  label: 'Bitcoin',  network: 'Bitcoin',          address: 'PASTE_BTC_ADDRESS' },
  { id: 'eth',  label: 'Ethereum', network: 'ERC20 (Ethereum)', address: 'PASTE_ETH_ADDRESS' },
].filter((w) => !w.address.startsWith('PASTE_'));
```

به‌جای `PASTE_...` آدرس واقعی را بگذار.

> ✅ **محافظ خودکار:** هر آدرسی که هنوز با `PASTE_` شروع شود، از برنامه
> مخفی می‌ماند. اگر فقط USDT را پر کنی، فقط همان نمایش داده می‌شود.
> اگر هیچ‌کدام را پر نکنی، کل بخش دونیت پنهان می‌شود و فقط راه‌های رایگان
> می‌ماند — پس هیچ‌وقت آدرس ناقص به کسی نشان داده نمی‌شود.
