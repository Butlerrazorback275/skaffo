# ☕ Support Skaffo

**Skaffo is free and always will be.** Every feature is unlocked — there is no
paid tier, no trial, no telemetry, and no account. It runs entirely on your
machine and your projects never leave it.

## Crypto

Only if Skaffo genuinely saved you time. Nothing in the app changes either
way — there is nothing to unlock.

### USDT / USDC — Polygon  ← cheapest
```

```
Fees are a fraction of a cent. Send **only** on the Polygon network.

### Ethereum — ERC20
```
0x74203660a1EF78B686EC61D4A17B56498e83F636
```
Also accepts USDT/USDC on ERC20, but Ethereum fees are high for small amounts.

> ⚠️ **Always match the network to the address.** The Polygon and Ethereum
> addresses look identical because they are the same key — but the coins must
> be sent on the network you selected, or they are lost.
